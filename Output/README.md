# Java Multi-Client Chat Application

## Project Description

This project is developed for the **Distributed Systems** course.

It allows multiple clients to communicate using **Java Socket Programming**.

## Key Features

- Socket Programming
- Multithreading
- Message Broadcasting
- Java Swing GUI

## Technologies Used

1. Java
2. Java Sockets
3. Java Swing
